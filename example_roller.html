Basic Dice

The standard seven polyhedrals. Write as NdS where N is the number of dice and S is the number of sides.

1d4 1d6 1d8 1d10 1d12 1d20 1d100 old-skool character gen

Bonuses

Add or subtract a fixed value with +N or -N at the end of the expression.

1d20+5 1d20-1 2d6+3

Keep Highest / Lowest

Roll extra dice and keep only some. Use khN to keep the highest N dice, or klN to keep the lowest N. This is how advantage and disadvantage work in 5e.

advantage disadvantage 2d20kh1+5 2d20kl1-1

Drop Highest / Lowest

Roll extra dice and discard some. Use dlN to drop the lowest N dice, or dhN to drop the highest N.

one ability score roll all six at once roll preassigned 5d6dl2 4d6dh1

Reroll Below (Once)

Use rbN to reroll any dice that land below N, but only once per die. This is the Halfling Luck trait, rerolling natural 1s only the first time.

halfling luck great weapon fighting 1d20rb2

Reroll Below (Multiple)

Use rmN to keep rerolling dice below N until all dice show at least N. Unlike rb, this continues until the condition is satisfied.

keep rerolling below 10 reroll all 1s and 2s 2d6rm3

Minimum Value

Use mN to treat any die result below N as if it were N. This is how Reliable Talent works — you can't roll below 10.

reliable talent reliable talent +11 1d20m10

Reroll Minimum Total

Use rmtN to reroll all dice if the total (after other modifiers) is below N. Useful for ability score generation where you want to guarantee a minimum result.

ability score (min 6) above average character 3d6rmt10

Labels

Prefix an expression with label: to group dice by damage type or other category. Separate multiple expressions with spaces.

fireball flame strike ice storm fire:2d6 slashing:1d8+3 fire:1d6

Complex Examples

Combine modifiers for advanced rolls. Modifiers are applied left to right before the bonus, so ordering matters.

4d6rb3kh1 4d6kh1rb3 fire:3d10rm8+2 cold:2d20kh1rb15 force:1d12m10-1
